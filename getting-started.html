Before you start

Getting set up

You don't need anything installed to read the lessons — the animated demos and quizzes all run right here in your browser. But whenever a chapter asks you to "try it yourself," you'll want a real place to run C++ code. Pick one option below.

Option A — an online compiler (fastest, 0 install)

Great for the first few chapters while you're just getting a feel for the language.

  • onlinegdb.com — pick "C++" as the language, paste code, click Run.
  • godbolt.org — great once you're curious what the compiler actually does.
  • replit.com — create a free "C++" repl if you want your work saved.

Tip

Every code example in this course is short enough to copy, paste, and run in about 10 seconds using any of these.

Option B — install a compiler on your computer

Worth doing once you're past the first few chapters and want a permanent setup.

Windows

  1. Install Visual Studio Code (a free code editor).
  2. Install the MSYS2 or MinGW-w64 toolchain to get the g++ compiler, or install the "Desktop development with C++" workload from Visual Studio Community.
  3. In VS Code, install the "C/C++" extension from Microsoft.

macOS

  1. Open Terminal and run xcode-select --install to get Apple's Clang compiler (which understands C++).
  2. Install Visual Studio Code and its "C/C++" extension.

Linux

  1. Install the GNU toolchain, e.g. on Debian/Ubuntu: sudo apt install build-essential.
  2. Use any editor you like — VS Code, vim, or otherwise.

Compiling and running from the command line

g++ -std=c++17 -o hello hello.cpp
./hello

The first line compiles hello.cpp into a program named hello. The second line runs that program. You'll see exactly this two-step pattern explained with an animation in Chapter 1.

How to use this site

  • Chapters are meant to be read in order — each one builds on the last.
  • Every animated demo has Step and Play buttons — use Step if you want to think about each change before it happens.
  • Exercises grade themselves instantly. Getting one wrong is expected and useful — read the feedback and try again.
  • Tick "Mark chapter complete" at the bottom of a chapter to track your progress on the home page. This is stored only in your browser (nothing is uploaded anywhere).

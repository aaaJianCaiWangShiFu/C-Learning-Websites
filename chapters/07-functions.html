Chapter 7

Functions & the Call Stack

A function is a named, reusable block of code. Instead of copy-pasting the same logic everywhere, you write it once and call it whenever you need it.

Defining and calling a function

int square(int n) {
    return n * n;
}

int main() {
    int result = square(5);
    std::cout << result << std::endl;
    return 0;
}

Anatomy of int square(int n):

  • int (first) — the return type: the type of value this function hands back.
  • square — the function's name.
  • (int n) — the parameter list: n is a local variable that receives whatever value is passed in when the function is called.
  • return n * n; — computes a value and immediately exits the function, handing that value back to the caller.

How a call actually runs — the call stack

When main calls square(5), the computer doesn't just jump there and forget where it came from. It pushes a new stack frame — a little record of "I'm inside square, and I'll come back to this exact spot in main when it's done." When the function returns, that frame is popped off and control resumes right where it left off.

Parameters vs. arguments

Parameters are the placeholder variables in the function's definition. Arguments are the actual values you pass in when calling it. C++ passes arguments by value by default — the function gets its own copy, so changing a parameter inside the function does not affect the caller's variable.

void tryToChange(int x) {
    x = 100; // only changes the local copy
}

int main() {
    int value = 5;
    tryToChange(value);
    std::cout << value << std::endl; // still 5
    return 0;
}

Functions that return nothing: void

void greet(std::string name) {
    std::cout << "Hello, " << name << "!" << std::endl;
}

int main() {
    greet("Sam");   // no return value to store
    return 0;
}

Why bother with functions?

  • Reuse — write the logic once, call it from many places.
  • Readability — double area = circleArea(radius); reads better than the raw formula inline, every time.
  • Testability — you can test a function in isolation.

Show a sample solution 
bool isEven(int n) {
    return n % 2 == 0;
}

int main() {
    std::cout << isEven(17) << std::endl; // prints 0 (false)
    return 0;
}

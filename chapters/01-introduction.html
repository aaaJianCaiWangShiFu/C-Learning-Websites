Chapter 1

How C++ Programs Work

Before writing a single line of code, let's build a mental model of what a "program" actually is, and what happens when you turn source code into something a computer can run.

What is C++?

C++ is a compiled, general-purpose programming language. People use it to build video games, web browsers, operating systems, and software that needs to run fast. Unlike some languages, C++ doesn't run directly — it has to be translated into instructions your computer's processor understands. That translation step is called compiling.

Source code → compiler → program

You write source code in a plain text file (with a .cpp extension). A program called a compiler reads that text and translates it into an executable — a file made of machine instructions your computer can actually run. Step through the pipeline below to see the journey a program takes.

Your first program

Here is the smallest complete C++ program that does something visible: it prints a greeting to the screen.

hello.cppC++
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}
Hello, World!

Let's break down every piece:

  • #include <iostream> — pulls in the standard library code needed for console input/output (the "i" and "o" in "iostream").
  • int main() { ... } — every C++ program has exactly one main function. It's the entry point: execution always starts at the first line inside main.
  • std::cout << "Hello, World!" — sends ("streams") the text "Hello, World!" to console output. The << operator means "send this into that stream."
  • std::endl — ends the current line (like pressing Enter).
  • return 0; — tells the operating system the program finished successfully. 0 conventionally means "no errors."
  • Every statement ends with a semicolon ; — C++'s way of knowing where one instruction ends and the next begins.

Why std::?

cout and endl live inside a "namespace" called std (short for standard), which groups together names from the standard library so they don't clash with names you choose yourself. std::cout means "the cout that lives inside std." You'll see this pattern constantly.

Comments

Comments are notes for humans that the compiler ignores completely. Use them to explain why, not what — the code already says what it does.

// This is a single-line comment.

/* This is a
   multi-line comment. */

int main() {
    // Print a greeting
    std::cout << "Hi there!" << std::endl;
    return 0;
}

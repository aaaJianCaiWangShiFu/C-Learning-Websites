Chapter 9

Working with Strings

Text is everywhere in real programs — names, messages, file paths. C++'s std::string (from <string>) is really just an array of characters under the hood, wrapped with convenient tools.

A string is a sequence of characters

#include <string>

std::string word = "cats";

Just like an array, each character has an index starting at 0:

Useful string operations

std::string name = "Ada";

std::cout << name.length() << std::endl;      // 3
std::cout << name[0] << std::endl;             // 'A'
std::cout << name + " Lovelace" << std::endl;  // "Ada Lovelace"

name += "!!!";                                  // name is now "Ada!!!"
std::cout << name << std::endl;

std::string sentence = "Hello, World!";
std::cout << sentence.substr(7, 5) << std::endl; // "World" — 5 chars starting at index 7
OperationWhat it does
s.length()number of characters
s[i]the character at index i
s1 + s2concatenation (joins two strings)
s += "..."append text to the end
s.substr(start, len)extract a piece of the string
s.find("x")index where "x" first appears, or std::string::npos if absent
s1 == s2true if the text is identical

Comparing strings

Unlike some languages, C++'s == works correctly on std::string and compares actual text content:

std::string a = "cat";
std::string b = "cat";
std::cout << (a == b) << std::endl; // 1 (true)

Looping over characters

std::string word = "hello";
for (char c : word) {
    std::cout << c << "-";
}

std::string vs. C-style char arrays

C++ inherited a more primitive text type from C: char name[] = "Ada";. You'll see it occasionally in older code, but std::string is safer and far easier to use — prefer it for everything in this course and in your own projects.

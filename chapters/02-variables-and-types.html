Chapter 2

Variables, Types & Memory

A variable is a named box in your computer's memory that holds a value. In this chapter you'll learn how to create them, what kinds of values they can hold, and what's really happening underneath.

Declaring a variable

To create a variable in C++ you state its type (what kind of value it holds), give it a name, and optionally give it a starting value:

int age = 25;
double price = 19.99;
char grade = 'A';
bool isRaining = false;
std::string name = "Maya";

Think of each variable as a labeled box. The type tells the compiler how big the box needs to be and what kind of data is allowed inside it.

A "byte" is 8 bits, and a bit is a single 0-or-1 switch. An int reserves 4 bytes — 32 switches — enough to represent about 4 billion distinct values.

C++ is statically typed

Once you declare a variable's type, it can never change. You can't put text into an int box. The compiler checks this before your program even runs, which catches a huge class of bugs early.

Reassigning values

You can change what's inside a box any time, as long as the new value matches the box's type:

int score = 0;
score = 10;      // score is now 10
score = score + 5; // score is now 15

score = score + 5; means: compute score + 5 using the current value first, then store the result back into score.

Constants

Sometimes you want a value that's never allowed to change. Use const:

const double PI = 3.14159;
// PI = 3;  // this line would fail to compile

sizeof and auto

You can ask the compiler how many bytes a type uses with sizeof, and you can let it infer a variable's type from its initial value with auto:

std::cout << sizeof(int) << std::endl;   // 4 (on most systems)
auto count = 10;       // count is deduced to be int
auto ratio = 0.5;      // ratio is deduced to be double

Recursion

Back in Chapter 7 you saw that every function call pushes a stack frame. Nothing stops a function from calling itself — that's recursion, and the call stack is exactly what makes it work.

A recursive function has two parts

  • Base case — the simplest input, answered directly, with no further recursive call. Without this, recursion never stops.
  • Recursive case — solves a smaller version of the problem by calling itself, then combines that result into the current answer.

Classic example: factorial

factorial(n) (written n!) means n × (n-1) × (n-2) × ... × 1. Notice that factorial(n) = n × factorial(n - 1) — the problem contains a smaller version of itself.

int factorial(int n) {
    if (n <= 1) {
        return 1;               // base case
    }
    return n * factorial(n - 1); // recursive case
}
Demo — watch factorial(4) unfold on the call stack
Frames pile up until the base case is hit, then each one returns and pops off, multiplying as it goes.

Here's the sequence in words: factorial(4) needs factorial(3), which needs factorial(2), which needs factorial(1) — the base case, which returns 1 immediately with no further calls. Then each waiting call finishes its multiplication and returns, from the bottom up: 1 → 2×1=2 → 3×2=6 → 4×6=24.

Forgetting the base case = infinite recursion

Just like a loop with no way to stop, a recursive function with no base case (or one that's never reached) will call itself forever — until it exhausts the call stack and crashes with a "stack overflow."

Recursion vs. a loop

Anything recursion can do, a loop can usually do too — and often faster, since it avoids the overhead of many function calls. Recursion tends to shine when a problem is naturally defined in terms of smaller versions of itself (tree structures, divide-and-conquer algorithms). Here's the same factorial with a loop, for comparison:

int factorialLoop(int n) {
    int result = 1;
    for (int i = 2; i <= n; i++) {
        result *= i;
    }
    return result;
}

Another example: Fibonacci

int fibonacci(int n) {
    if (n <= 1) {
        return n;                                  // base case
    }
    return fibonacci(n - 1) + fibonacci(n - 2);      // recursive case
}

This one makes two recursive calls per step — the call "tree" branches, rather than forming a single chain. It's elegant but, for large n, quite slow, since it recomputes the same smaller values over and over.

Exercise 3 — Write it yourself

Write a recursive function int sumTo(int n) that returns the sum of all whole numbers from 1 to n (e.g. sumTo(4) is 1+2+3+4 = 10). Identify your base case first.

Show a sample solution 
int sumTo(int n) {
    if (n <= 1) {
        return n;              // base case
    }
    return n + sumTo(n - 1);   // recursive case
}

int main() {
    std::cout << sumTo(4) << std::endl; // 10
    return 0;
}

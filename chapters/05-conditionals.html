Chapter 5

Making Decisions

Real programs don't just run top to bottom — they branch, choosing different code to run depending on conditions. This is where bool expressions from Chapter 3 become powerful.

The if statement

int age = 20;

if (age >= 18) {
    std::cout << "You can vote." << std::endl;
}

The code inside { } only runs if the condition in ( ) evaluates to true. If it's false, that block is skipped entirely.

if / else

if (age >= 18) {
    std::cout << "You can vote." << std::endl;
} else {
    std::cout << "Not yet — come back later." << std::endl;
}

Chaining with else if

Use this to check several conditions in order. C++ checks them top to bottom and runs the first one that's true, then skips the rest.

int score = 72;

if (score >= 90) {
    std::cout << "Grade: A" << std::endl;
} else if (score >= 80) {
    std::cout << "Grade: B" << std::endl;
} else if (score >= 70) {
    std::cout << "Grade: C" << std::endl;
} else {
    std::cout << "Grade: F" << std::endl;
}
Grade: C

Even though score >= 70 and it's technically also true that nothing lower applies, only the first matching branch runs — the rest are skipped automatically.

Combining conditions

bool hasTicket = true;
int age = 15;

if (age >= 18 || hasTicket) {
    std::cout << "Entry allowed." << std::endl;
}

if (age >= 13 && age < 20) {
    std::cout << "Teenager." << std::endl;
}

The switch statement

When you're comparing one variable against several exact values, switch can be more readable than a long else if chain. Don't forget break; — without it, execution "falls through" into the next case.

int day = 3;

switch (day) {
    case 1:
        std::cout << "Monday" << std::endl;
        break;
    case 2:
        std::cout << "Tuesday" << std::endl;
        break;
    case 3:
        std::cout << "Wednesday" << std::endl;
        break;
    default:
        std::cout << "Some other day" << std::endl;
}
Wednesday

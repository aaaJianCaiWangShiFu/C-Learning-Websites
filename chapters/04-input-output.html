Chapter 4

Input & Output

So far your programs have only printed fixed text. Real programs react to what the user types. C++ uses std::cout to write to the console and std::cin to read from it.

Reading a single value

#include <iostream>

int main() {
    int age;
    std::cout << "How old are you? ";
    std::cin >> age;
    std::cout << "You are " << age << " years old." << std::endl;
    return 0;
}

std::cin >> age; pauses the program, waits for the user to type something and press Enter, then converts that text into a number and stores it in age. Notice the arrows point the opposite way from cout: data flows into your variable.

#include <iostream>
#include <string>

int main() {
    std::string name;
    int age;

    std::cout << "What is your name? ";
    std::cin >> name;

    std::cout << "How old are you? ";
    std::cin >> age;

    std::cout << "Hi " << name << "! In 10 years you'll be " << (age + 10) << "." << std::endl;
    return 0;
}

Reading more than one value at once

You can chain multiple >> in one statement. The user can separate values with spaces or new lines:

int width, height;
std::cout << "Enter width and height: ";
std::cin >> width >> height;

std::cin >> stops at whitespace

std::cin >> name only reads a single "word" — it stops at the first space. To read a whole line (like "Ada Lovelace"), use std::getline(std::cin, name); instead.

Building output with <<

You can chain as many values as you like onto a single cout statement — text, numbers, and variables all mixed together:

int x = 3, y = 4;
std::cout << "The point (" << x << ", " << y << ") is " << (x + y) << " units from the origin (by taxicab distance)." << std::endl;
The point (3, 4) is 7 units from the origin (by taxicab distance).

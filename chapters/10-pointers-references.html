Chapter 10

Pointers & References

This is the chapter that trips up most beginners — take it slowly. Every variable lives at some address in memory. A pointer is simply a variable that stores an address instead of an ordinary value.

Every variable has an address

Use & in front of a variable to ask "where do you live in memory?" — this is the address-of operator.

int x = 42;
std::cout << x << std::endl;   // 42            (the value)
std::cout << &x << std::endl;  // 0x7ffee2a3c   (the address — yours will differ)

A pointer stores an address

int x = 42;
int* px = &x;   // px "points to" x

int* means "a pointer to an int." px doesn't hold 42 — it holds the address where 42 lives.

Dereferencing: following the arrow

* in front of a pointer means "go to the address it holds, and give me the value that's actually there" — this is the dereference operator.

int x = 42;
int* px = &x;

std::cout << *px << std::endl;  // 42   — the value at the address px holds

*px = 100;                       // follow the pointer, change what's there
std::cout << x << std::endl;    // 100  — x itself changed!

Two very different jobs for * and &

In a declaration, int* px means "px is a pointer." In an expression, *px means "the value px points to." Similarly, & in a declaration (int& rx) means "reference," but in an expression (&x) means "address of." Context tells you which.

References — a simpler alias

A reference is like a permanent nickname for an existing variable. Once bound, it can never point anywhere else, and you never need * to use it — it behaves exactly like the original:

int x = 42;
int& rx = x;   // rx is now another name for x

rx = 100;               // this changes x directly
std::cout << x;         // 100

Why this matters: passing by reference

Recall from Chapter 7 that functions copy their arguments by default. If you want a function to actually modify the caller's variable, pass a reference:

void doubleIt(int& n) {
    n = n * 2;   // modifies the caller's variable directly
}

int main() {
    int value = 5;
    doubleIt(value);
    std::cout << value << std::endl; // 10 — changed!
    return 0;
}

Compare this to Chapter 7's tryToChange(int x) example, which used a plain copy and could not change the caller's variable. This one small & is the difference.

Exercise 3 — Write it yourself

Write a function void swapValues(int& a, int& b) that swaps two variables' values using references, and call it from main on two ints, printing them before and after.

Show a sample solution 
void swapValues(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 1, y = 2;
    std::cout << x << " " << y << std::endl; // 1 2
    swapValues(x, y);
    std::cout << x << " " << y << std::endl; // 2 1
    return 0;
}

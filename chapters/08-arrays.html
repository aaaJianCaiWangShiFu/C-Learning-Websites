Chapter 8

Arrays & Vectors

So far every variable has held exactly one value. An array holds a whole row of values of the same type, side by side in memory, each reachable by a numeric index.

Declaring an array

int scores[5] = {90, 85, 77, 92, 60};

This reserves room for exactly 5 ints in a row. Each slot has an index starting at 0, not 1:

Off-by-one is the classic array bug

An array of size 5 has valid indices 0 through 4. Accessing scores[5] reads memory outside the array — C++ won't stop you, and the result is undefined behavior (often garbage values or a crash).

Looping over an array

int scores[5] = {90, 85, 77, 92, 60};
int sum = 0;

for (int i = 0; i < 5; i++) {
    sum = sum + scores[i];
}
std::cout << "Total: " << sum << std::endl;
Demo — summing an array with a loop
Step through the loop and watch i, the current element, and sum all update.

The range-based for loop

When you don't need the index, this is cleaner:

for (int score : scores) {
    std::cout << score << std::endl;
}

std::vector — an array that can grow

Plain arrays have a fixed size decided at compile time. std::vector (from <vector>) is a resizable alternative used constantly in real C++ code:

#include <vector>

std::vector<int> scores = {90, 85, 77};
scores.push_back(100);          // add to the end → {90, 85, 77, 100}
std::cout << scores.size();     // 4
std::cout << scores[0];         // 90, indexing works just like arrays

When in doubt, prefer std::vector — it's just as fast for most purposes and far more flexible.

Exercise 3 — Write it yourself

Write a program that stores 5 numbers in a std::vector<int>, then loops over it to print the largest value.

Show a sample solution 
#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums = {4, 19, 7, 42, 11};
    int largest = nums[0];

    for (int n : nums) {
        if (n > largest) {
            largest = n;
        }
    }
    std::cout << largest << std::endl; // 42
    return 0;
}

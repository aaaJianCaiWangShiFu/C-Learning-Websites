Chapter 11

Structs, Classes & Objects

So far, related data has lived in separate variables — a name, a breed, an age, all disconnected. A struct lets you bundle them into a single custom type.

Defining a struct

struct Dog {
    std::string name;
    std::string breed;
    int age;
};

Dog is now a new type, just like int or std::string — except you defined it. Create ("instantiate") a Dog and access its fields with a dot:

Dog myDog;
myDog.name = "Rex";
myDog.breed = "Labrador";
myDog.age = 3;

std::cout << myDog.name << " is " << myDog.age << " years old." << std::endl;
Demo — building an object field by field
All three fields live together inside one Dog object.

You can also initialize all fields at once:

Dog myDog = {"Rex", "Labrador", 3};

From struct to class: adding behavior

A class works almost identically to a struct, but is built for bundling data and the functions that operate on it together. Functions inside a class are called methods, called on a specific object with the dot operator.

class Dog {
public:
    std::string name;
    std::string breed;
    int age;

    void bark() {
        std::cout << name << " says: Woof!" << std::endl;
    }

    bool isPuppy() {
        return age < 1;
    }
};

int main() {
    Dog myDog;
    myDog.name = "Rex";
    myDog.age = 3;

    myDog.bark();                              // "Rex says: Woof!"
    std::cout << myDog.isPuppy() << std::endl; // 0 (false)
    return 0;
}

struct vs. class

In C++ these are nearly the same thing — the only default difference is visibility (struct members are public by default; class members are private). Convention: use struct for simple data bundles, class when you're adding meaningful behavior or want to hide internal details.

public and private

public members can be accessed from anywhere. private members can only be accessed from inside the class's own methods — this lets a class protect its internal data and guarantee it stays valid.

class BankAccount {
private:
    double balance;   // outside code cannot touch this directly

public:
    void deposit(double amount) {
        if (amount > 0) balance += amount;   // validated here
    }
    double getBalance() {
        return balance;
    }
};

Constructors

A constructor is a special method that runs automatically when an object is created, useful for guaranteeing every object starts in a valid state:

class Dog {
public:
    std::string name;
    int age;

    Dog(std::string n, int a) {   // constructor: same name as the class, no return type
        name = n;
        age = a;
    }
};

int main() {
    Dog myDog("Rex", 3);   // calls the constructor automatically
    std::cout << myDog.name << std::endl;
    return 0;
}

Exercise 3 — Write it yourself

Write a class Rectangle with double width and double height, a constructor that sets both, and a method double area() that returns width * height. Create one in main and print its area.

Show a sample solution 
class Rectangle {
public:
    double width;
    double height;

    Rectangle(double w, double h) {
        width = w;
        height = h;
    }

    double area() {
        return width * height;
    }
};

int main() {
    Rectangle r(4.0, 5.5);
    std::cout << r.area() << std::endl; // 22
    return 0;
}
